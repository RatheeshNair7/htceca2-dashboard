One-time Setup

🔥 Firebase Setup

Connect a free real-time database so all teammates share the same data instantly.

Current Status
Checking…
Once connected:
✅ All teammates share live data
1
Create a free Firebase project

Go to console.firebase.google.com and sign in with your Google account.

  1. Click "Add project"
  2. Name it htceca2 (or anything)
  3. Disable Google Analytics (not needed) → click "Create project"
2
Enable Firestore Database
  1. In the left sidebar click Build → Firestore Database
  2. Click "Create database"
  3. Choose Start in test mode → click Next
  4. Select europe-west1 (closest to Netherlands) → Enable
3
Get your config keys
  1. Go to Project Settings (gear ⚙️ icon, top left)
  2. Scroll to "Your apps" → click the </> Web icon
  3. Register the app (any name, e.g. htceca2-web)
  4. You'll see a firebaseConfig object with all the keys
4
Paste your config into index.html

Open index.html in any text editor and find the section near the top that says:

const FIREBASE_CONFIG = {
  apiKey:            "PASTE_YOUR_API_KEY_HERE",
  authDomain:        "PASTE_YOUR_AUTH_DOMAIN_HERE",
  projectId:         "PASTE_YOUR_PROJECT_ID_HERE",
  storageBucket:     "PASTE_YOUR_STORAGE_BUCKET_HERE",
  messagingSenderId: "PASTE_YOUR_MESSAGING_SENDER_ID_HERE",
  appId:             "PASTE_YOUR_APP_ID_HERE"
};

Replace each PASTE_YOUR_…_HERE with the values from your Firebase console. Save the file and re-upload to GitHub Pages.

5
Migrate your existing data (optional)

If you've already entered availability or scores locally, click below to push your local data up to Firebase so nothing is lost.
